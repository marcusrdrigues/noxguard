# noxguard

**Guardrails determinísticos para chats e agentes com LLM, em Java.** Uma guarda de saída para streaming que nunca deixa sair um vazamento e nunca segura a resposta inteira, lista de links permitidos, delimitação de dados, histórico assinado, portão de proposta para agentes e versões decodificadas da entrada para o seu classificador.

[Read in English](README.md)

> **Situação: v0.1 em construção. Nada publicado ainda.** O projeto começa pela especificação: o que está sendo construído e por quê está em [`docs/specs/0.1-core.md`](docs/specs/0.1-core.md) (em inglês).

O noxguard é o par do [noxeval](https://github.com/marcusrdrigues/noxeval): **o noxeval mede, o noxguard aplica.** Os dois vêm do [Nox](https://marcusrdrigues.com), o chat público do portfólio do autor.
